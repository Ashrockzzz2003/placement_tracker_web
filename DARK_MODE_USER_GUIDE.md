## 🎯 Quick Start

### For Everyone
1. Look at the **top-right corner** of any page
2. Click the **moon icon** (🌙) to enable dark mode
3. Click the **sun icon** (☀️) to switch back to light mode
4. Your preference is **automatically saved** and will be there next time!

## 💾 Your Preference is Saved

### First Time Using the App?
- The app checks your **operating system settings**
- If your OS is in dark mode → app starts in dark mode
- If your OS is in light mode → app starts in light mode
- **You can always override** by clicking the toggle

### After You Make a Choice
- Your preference is saved in your **browser's memory**
- It remembers **even after you close the app**
- Works across all **pages and visits**
- Persists **forever** (until you clear browser storage)

## ⚙️ System Preference Detection

### How It Works

**First Visit to the App:**
```
1. App checks your system settings
2. Looks for dark mode preference
3. Uses what it finds
4. You can override anytime
```

### Checking Your System Settings

**Windows 10/11:**
- Settings → Personalization → Colors
- Select "Dark" mode

**Mac:**
- System Preferences → General
- Choose "Dark" appearance

**Linux:**
- Settings → Appearance
- Enable "Dark Mode"

**iOS:**
- Settings → Display & Brightness
- Select "Dark" mode

**Android:**
- Settings → Display
- Enable "Dark Theme"

## 🐛 Troubleshooting

### The toggle button isn't showing?
**Solution:**
1. Refresh the page
2. Clear browser cache
3. Try a different browser

### Dark mode isn't saving?
**Solution:**
1. Check if your browser allows localStorage
2. Try incognito/private mode
3. Check browser privacy settings

### Text is hard to read?
**Solution:**
1. Try the other mode
2. Adjust your screen brightness
3. Check if auto-brightness is on

### Icons are too small?
**Solution:**
1. Pinch to zoom on mobile
2. Use browser zoom on desktop
3. Adjust display settings

## 🔐 Privacy & Storage

### What's Saved?
- Your dark mode preference (true/false)
- Stored in **browser storage** only
- **Not** sent to any server
- **Not** tracked or analyzed

### Where It's Stored?
- Browser's localStorage
- Only accessible to this app
- Cleared when you clear browser data

### How to Reset?
1. Open browser developer tools
2. Go to Storage/Application
3. Find localStorage
4. Delete "darkMode" entry
5. Refresh page

## ❓ FAQ

### Q: Will dark mode slow down the app?
**A:** No! It's extremely fast and lightweight.

### Q: Can I set specific colors?
**A:** Not in the UI, but developers can customize app/globals.css

### Q: Does dark mode work offline?
**A:** Yes! It's stored locally on your device.

### Q: Do I need to sign in again?
**A:** No! Dark mode is separate from login.

### Q: Can I have different modes per page?
**A:** No, it's app-wide (by design for consistency).

### Q: Is dark mode worse for my eyes?
**A:** Actually, it can be better in low light conditions!

### Q: What if my device doesn't support dark mode?
**A:** You can still use the toggle on the website.

### Q: Does it work on mobile?
**A:** Yes! Works perfectly on all mobile devices.
