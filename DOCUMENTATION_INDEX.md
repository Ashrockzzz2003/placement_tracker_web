## 📋 Quick Reference

### Essential Commands
```bash
npm install    # Install dependencies
npm run dev    # Start development
npm run build  # Build for production
npm start      # Run production
```

### Key Locations
- **Feature Code:** `util/ComparisonCharts.js`
- **Admin Integration:** `app/dashboard/admin/placement/page.js`
- **Manager Integration:** `app/dashboard/manager/placement/page.js`

### Access Points
- **Development:** `http://localhost:3000`
- **Backend API:** `http://localhost:5000/api`
- **Admin Dashboard:** Dashboard → Admin → Placements
- **Manager Dashboard:** Dashboard → Manager → Placements
